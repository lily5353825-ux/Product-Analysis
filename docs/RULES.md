# 加预算、降预算、调广告

本文件是规则引擎的实现规格；config/rules.json 是可调整参数，当前尚未接入自动计算或账户操作。所有阈值为初始建议，非 Walmart 官方规则；实际 SKU 目标填入 business.json。

## 必要前置与优先级
普通优化建议先检查配置 ready、目标/CPA/利润口径已填写、数据完整、币种/报表一致。未知项返回“数据不足”，不强行决策。库存为零/预算耗尽只在相关数据已确认完整且新鲜时优先提示；陈旧或未知数据不能被当作确定的紧急状态。
最近 7 个成熟完整广告日为默认效率观察窗；成熟截止日 = 数据覆盖日 − 已确认的 attribution_maturity_days。不得猜测平台归因窗口与延迟。
预算余额和最新花费检查使用最新完整日，不随成熟广告窗口后移。销售进度使用订单日；ACOS 使用广告报表日期，不混算不同窗口。

每个 SKU 按如下顺序仅输出一个主建议，可附诊断提示：
1. 库存为 0 或周期预算已耗尽：建议暂停/降预算，人工确认。不受普通样本门槛限制。
2. 数据不足：继续观察/补数据。
3. 距离上次实际预算或广告操作不足 72 小时：继续观察；紧急超支/断货例外。
4. 效率差或节奏超前：降预算。
5. 效率好且预算受限：加预算。
6. 漏斗异常或预算跑不动：调广告。
7. 其他：保持并观察。

## 规则条件
| 建议 | 触发条件 | 幅度/行动 |
|---|---|---|
| 加预算 | 最近成熟窗至少 30 次点击、3 个归因订单；ACOS <= 商品目标 ACOS；最新同期 TACOS <= 商品目标 TACOS；GMV 低于同期目标；最近 3 个完整日每日预算使用率均 >=90%；花费节奏 <=110%；库存可售天数 >=14；周期剩余额度足够 | SKU 当前日预算增加 15%，受剩余预算约束；展示建议金额后人工分配到 campaign |
| 降预算：效率差 | 成熟窗至少 30 次点击，且归因订单 >=3、ACOS > 目标 ACOS ×1.2；或零归因订单且花费 >=目标 CPA ×2（即使零分母也可判定） | 日预算降低 20%，检查相关关键词/商品页 |
| 降预算：超前 | 最新累计花费 / 同期计划预算 >110%，且 GMV 未达到同期目标；或按当前日预算运行会超出周期剩余额度 | 降低 20% 或降至可持续日预算，以更低者为准 |
| 调广告：点击弱 | 曝光 >=1000 且 CTR <业务配置的 CTR 下限 | 检查关键词相关性、主图、标题；CTR 下限未配置时不触发该分支 |
| 调广告：转化弱 | 成熟窗点击 >=30 且广告 CVR <业务配置的 CVR 下限 | 检查售价、详情、评价、配送和库存；先小范围测试 |
| 调广告：预算跑不动 | 最近 3 个完整日每日预算使用率均 <60%，且库存可售、广告处于 active | 检查出价、定向、搜索词覆盖；不因销量低直接加总预算 |
| 继续观察 | 样本不足、零分母且无零转化花费证据、冷却中或以上条件均不满足 | 明示缺失条件与下一次复核日期 |

“最新同期 TACOS”包含最新完整销售和花费，窗口一致；零 GMV 时未知，禁止加预算。单日预算使用率需合并同 SKU 所有 campaign 的花费和有效预算上限再计算。

## 限额
remaining = 周期计划预算 − 截至最新完整日花费。
remaining_days = 数据截止日之后至周期结束，daily_plan.ad_budget_cents > 0 的计划投放天数。零预算日不建议恢复投放。
remaining_days <= 0 时停止计算新日预算，显示“周期结束或无后续投放计划”。否则 sustainable_daily_cap = floor(max(remaining, 0) / remaining_days)。
增加后的日预算 = min(floor(当前日预算 ×1.15), sustainable_daily_cap)。
降低后的日预算 = min(floor(当前日预算 ×0.8), sustainable_daily_cap)。
若限额导致新值不高于当前日预算，不能输出“加预算”；改为保持/降预算并说明周期额度限制。当前日预算未知则不产生金额建议。

毛利率指扣除进货、履约、佣金、预期退货成本后，广告前贡献毛利率。目标 ACOS 必须低于该比率作为初步安全边界；归因销售与毛利口径需一致。它只是初筛，广告归因不等于增量收益，不能宣称投放一定盈利。

## 建议卡与审计
展示 SKU、主建议、观察窗、数据新鲜度、规则编号、触发指标/阈值、当前预算、建议预算、预计增减金额、阻止条件。执行由人员在广告平台完成，再记录 action_log；日志以实际执行时间开始冷却。建议生成时间不是执行时间。

## 新鲜度与当前预算来源
规则计算必须传入带时区的 as_of。最新报表批次导入距 as_of 不超过 48 小时，且最新完整数据日距业务当日不超过 2 天；库存 updated_at 不超过 48 小时且快照日期距业务当日不超过 2 天。阈值见 rules.json；日期覆盖不足或时间未知返回“数据不足”。成熟广告观察窗检查最新批次的完整性和新鲜度，不因历史行本身日期较老而判作过期。

当前日预算取 campaigns 中该 SKU 所有 active 活动的 current_daily_budget_cents 之和；每条均需 budget_confirmed_at，距 as_of 不超过 24 小时且不得在未来。由操作者从广告后台确认，不能以 ad_daily 的历史预算代替。任一当前预算未知/过期时只输出方向及“待确认当前预算”，不生成金额。相应上限适用于整个 SKU，而不是分别给每条 campaign 分配全部余额。

暂停动作在 action_log 中记录 action_type=decrease、new_daily_budget_cents=0，并在 reason 标明暂停原因。config/rules.json 的观察窗、幅度与新鲜度数值均为待业务确认的初始值。
