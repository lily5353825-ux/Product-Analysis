# 启动与部署

## 本地
需要 Node.js 22+。在仓库根目录依次运行：

~~~sh
node --test
node scripts/build.mjs
node scripts/serve.mjs
~~~

访问 http://127.0.0.1:4173。本地服务只监听本机，停止时按 Ctrl+C。浏览器需支持 DecompressionStream 的 deflate-raw（建议使用当前 Chrome 或 Edge）。网页不可直接双击HTML运行，因为使用ES模块。

## 网站
静态构建内容位于 dist。Sites 的站点 ID 和静态目录记录在 .openai/hosting.json，默认以仅本人可见方式发布。网站使用浏览器本地导入，不存储用户工作簿或账号密钥。

GitHub 仓库只保存源代码、配置、文档及合成测试数据。站点发布源由 Sites 的源仓库独立保存，须先同步确切版本再发布，保留部署版本便于回滚。

也可将 dist 交给静态托管服务。资源使用相对路径，可放在项目子目录；不需要API服务器、数据库或构建框架。没有自动向广告平台写入的接口。

## 使用限制
每次刷新需重新导入。导入器按当前工作簿版式校验；同订单同SKU多行、未知SKU、混币种或不明确的多件折扣/运费会报错，需先修正来源。完整覆盖和广告归因成熟性尚未核实，不能把文件中缺失记录等同于真实零交易。
