# 指标定义

## 时间与金额
订单按 ordered_date 归属；日期已转换成业务配置时区。日期筛选包含起止日。金额使用整数美分；展示时除以 100。币种不同不可直接合计。订单数与销量分别表示订单与件数。

## 销售与订单
对每条订单行：
- 有效件数 = quantity − cancelled_quantity。
- GMV = item_subtotal_cents − discount_cents − cancelled_net_cents。
- item_subtotal_cents 是原始商品金额，不含税费和运费；discount_cents 是该行全部折扣；cancelled_net_cents 是取消部分扣除对应折扣后的金额，避免重复扣减。
- GMV 不扣退货退款；净商品销售额 = GMV − refund_cents（不含税费/运费退款）。退款更新原订单行，因此历史数值会回补；此指标不是现金流口径。
- 订单数 = 有效件数 > 0 的 order_id 去重计数。全额退货但未取消的订单仍计订单；整单取消不计。
- 件数 = 有效件数求和。客单价 AOV = GMV / 去重订单数。
- 两款合计需对 order_id 再去重，不能相加 SKU 订单数；GMV/件数可加总。
- 不计算所谓“自然销售 = GMV − 广告归因销售”，因为日期和归因范围可能不同。

## 广告与预算
| 指标 | 公式 | 解释 |
|---|---|---|
| 广告费占 GMV（TACOS） | spend / GMV | 经营费用占比，原始值为小数，显示百分比 |
| 广告销售占比 | attributed_sales / GMV | 单独命名；日期基准不一致时标记“跨口径参考”，可能超过 100%，不能强制截断 |
| ACOS | spend / attributed_sales | 越低越好，但不独立决定扩量 |
| ROAS | attributed_sales / spend | 倍数 |
| CTR | clicks / impressions | 点击率 |
| CPC | spend / clicks | 每次点击成本 |
| 广告 CVR | attributed_orders / clicks | 使用同一广告报表、同一归因窗口 |
| 预算消耗 | spend / 所选周期计划预算 | 支出执行率，不是销售完成率 |
| 预算余额 | 周期计划预算 − spend | 负数即超支 |
| 花费节奏 | spend / 截至数据截止日计划预算 | 用于判断超前/偏慢 |
| 日预算使用率 | 当日 spend / 当日 campaign 有效预算上限 | 不是周期预算消耗；用于判断扩量受预算限制 |

预算调整建议以 SKU 为单位，再人工分配到归属于该 SKU 的 campaign。ad_daily 的 daily_budget_cap_cents 必须与当日有效预算对应；若日内多次变化无法还原，填空并禁用预算受限判断。

所有比率的分母为 0 返回 null，页面显示 N/A；不得显示 0%、Infinity。缺失字段应阻止导入或标记缺数据，而不是补零。
先求和后相除，不平均日 ACOS 或两个 SKU 的比率。广告归因订单不是店铺去重订单，不能相加到销售订单数。

## 可执行模块边界
src/domain/metrics.mjs 接收通过导入校验后的数组；订单用最新完整快照，广告表按唯一键去重。模块额外检查重复键、基本类型和金额约束；产品外键、日期完整覆盖、归因成熟度由后续导入层/规则层负责。空数组的销售合计为零，但 UI 必须依赖导入覆盖状态区分“确认零交易”与“缺数据”。

## 手工验算样例（合成数据）
订单 O1：A 商品 2 件，原价 20000 分、折扣 2000 分，其中取消 1 件净额 9000 分；B 商品 1 件 15000 分。
订单 O2：A 商品 1 件 10000 分、退款 2000 分。
另有全部取消订单 O3。
结果：GMV 34000 分、净商品销售额 32000 分、订单 2 单、件数 3、AOV 17000 分。
如果花费 3400 分、广告归因销售 17000 分，则 TACOS 10%、ACOS 20%、ROAS 5、广告销售占比 50%。

## 当前网页广告指标
广告表现区提供曝光、点击、平均 CPC、点击率 CTR、转化率 CVR 五张卡片，随经营日期及品类筛选同步更新；活动 × 商品明细使用同样的汇总口径。

- 曝光与点击分别求和；平均 CPC = 总花费 / 总点击；CTR = 总点击 / 总曝光；CVR = 广告归因订单合计 / 总点击。
- 不平均每日或各 SKU 的比率。CPC 底层为美分，展示为美元；CTR 与 CVR 展示百分比。
- 无广告记录或比率分母为 0 时展示「—」；有记录且数值确为 0 时显示 0。
- CVR 使用广告报表归因订单，而非销售表去重订单；当前归因窗口尚待确认，不用于自动调预算。
- 平台 SKU 排名来自单独手动导入的排名快照，不由这些曝光 / 点击数量推算；参见 IMPORT_RANKINGS.md。
