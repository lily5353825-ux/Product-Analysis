# 导入与查看 SKU 排名历史

排名来自 Walmart 后台或其他已确认的外部报表，由人员导出后导入。看板不根据广告曝光量、点击量或销售额自行生成名次；排名与经营数据分开导入、筛选。

## 操作步骤

1. 按下方字段整理 UTF-8 CSV 或 XLSX，每行记录一个日期、一个 SKU 的排名快照。SKU 与 Item ID 在 Excel 中设为文本，保留前导零，避免长编号被舍入。
2. XLSX 使用单个工作表；如果文件有多个工作表，将需要导入的工作表命名为 `SKU排名`。第一行为字段名，不要合并表头。
3. 在 SKU 排名模块选择文件。导入后，用该模块自己的日期和产品类别筛选查看快照与历史变化；这些筛选独立于上方经营看板的日期、品类筛选。
4. 后续导入新的日期会追加历史；再次导入同一日期、同一 SKU，会以新记录覆盖该快照。更新时提供完整行，未填的排名保持缺失，不自动沿用旧值。

记录仅保存在当前浏览器内存；刷新、关闭页面后需要重新导入。请在本地维护一份包含全部日期的累计 CSV，下次导入累计文件即可恢复历史。不要把含实际经营数据的文件提交到公开仓库。

## 字段与模板

字段名保持如下写法；日期、SKU、产品类别、商品类型必填，每行还须至少填写一项排名。

| 字段 | 要求 |
|---|---|
| 日期 | 必填，`YYYY-MM-DD`，表示这次报表快照的日期 |
| SKU | 必填，逐 SKU 记录，按文本保存 |
| Item ID | 可空，按文本保存 |
| 商品名称 | 可空，用于识别商品 |
| 产品类别 | 必填，只填 `106英寸组合沙发` 或 `79英寸沙发床` |
| 商品类型 | 必填，填写来源报表的 Product Type 类目，例如 `Sectional Sofas` 或 `Sofas & Couches`；同一 SKU 的历史比较应保持类目一致 |
| 商品状态 | 可空，保留来源报表中的状态文字 |
| 曝光排名 | 可空，已知时填写大于等于 1 的整数 |
| 点击排名 | 可空，已知时填写大于等于 1 的整数 |
| 加购排名 | 可空，已知时填写大于等于 1 的整数 |
| 销售排名 | 可空，已知时填写大于等于 1 的整数 |

可复制下面的表头和合成示例。示例不代表实际商品表现。

```csv
日期,SKU,Item ID,商品名称,产品类别,商品类型,商品状态,曝光排名,点击排名,加购排名,销售排名
2026-10-28,DEMO-106-GREY,,演示灰色组合沙发,106英寸组合沙发,Sectional Sofas,在售,120,95,,80
2026-10-29,DEMO-106-GREY,,演示灰色组合沙发,106英寸组合沙发,Sectional Sofas,在售,108,90,,76
2026-10-29,DEMO-79-BLUE,,演示蓝色沙发床,79英寸沙发床,Sofas & Couches,在售,210,,,130
```

空白表示未提供或未知，不能填写 `0` 代替。不要把 `—`、`N/A`、未上榜等文字填入数字排名列；无法获得数值时留空。CSV 中含逗号的商品名称等文本需用双引号包裹。

## 如何解读排名变化

- 数字越小，排名越靠前。
- 变化名次 = 上次排名 − 当前排名。例如 120 → 108 为上升 12 名；108 → 120 为下降 12 名。
- 没有可比历史记录，或对应排名缺失时，显示缺少比较依据；不能把空白当 0 计算升降。
- 日期表示同一统计口径的报表快照，并不意味着排名仅统计当天。比较历史时，应保持报表统计时间窗、站点、排名范围与 Product Type 类目一致。不要把近 7 天排名和近 30 天排名直接比较。

## 产品与变体的区别

来源页面可能同时展示产品与变体。每一行必须对应实际取得排名的 SKU；不能把父商品的排名复制给所有颜色或左右向 SKU。

如果报表只提供父商品信息，请先在后台展开变体并导出逐 SKU 排名，再整理导入。暂时无法获取某个 SKU 的排名，就保留缺失，不根据父商品排名猜测。`商品类型` 指 Product Type 类目，不表示父商品或变体层级；填写类目不能替代逐 SKU 核对。
